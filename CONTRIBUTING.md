# Contributing

This is a live document and will evolve alongside the project. As a novice when it comes to open-source, I ([GTLugo]) welcome contributions from anyone so long as they follow the general guidelines below and adhere to the Rust Code of Conduct.

When contributing, I recommend discussing the changes you look to make before you make them to avoid wasted effort. As a general rule, anything in the repo is up for grabs for changes so long as it does not significantly affect the user-facing API of the crate. 
If the proposed changes would affect the API, you may still propose the changes, but it will be less likely that they will be approved.

Unstable features of rustfmt are in use, so ensure you run `cargo +nightly fmt` before submitting.

Cross-platform is a key feature, so ideally you should test your code against as many supported platforms as you can. Tests aren't currently automated, which I do apologize for.
